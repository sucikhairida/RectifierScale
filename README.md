# RectifierScale

Multi-threaded RectifierScale is a high-performance data processing engine that enables real-time analytics on large datasets via auto-scaling platform.

With RectifierScale, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/RectifierScale.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
